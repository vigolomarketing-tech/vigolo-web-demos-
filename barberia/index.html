FAQ

Preguntas frecuentes.

Todo lo que necesitás saber antes de reservar.

¿Necesito reservar turno o puedo ir sin cita?

Podés venir sin turno, pero recomendamos reservar para no esperar. Esta demo muestra cómo el cliente reserva online y confirma por WhatsApp.

¿Qué medios de pago aceptan?

Efectivo, débito, crédito y transferencia. En la web real se puede sumar seña online para reducir ausencias.

¿Puedo elegir mi barbero?

Sí. Al reservar elegís el barbero de tu confianza y el sistema muestra su disponibilidad.

¿La web funciona en celular?

Totalmente. Está diseñada mobile-first, carga rápido y es compatible con GitHub Pages.
