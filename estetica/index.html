¿Cómo reservo un turno?

Elegís tratamiento, profesional y horario en la web, y confirmás por WhatsApp. Esta demo muestra ese flujo completo sin necesidad de backend.

¿Necesito una evaluación previa?

Sí, la primera sesión incluye una evaluación sin cargo para personalizar tu tratamiento y objetivos.

¿Qué medios de pago aceptan?

Efectivo, débito, crédito y transferencia. En la web real se puede sumar seña online para asegurar el turno.

¿La web funciona en celular?

Totalmente. Está diseñada mobile-first, carga rápido y es compatible con GitHub Pages.
